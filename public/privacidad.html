Privacidad

La cookie técnica de sesión dura hasta 180 días. Si la borras o cambias de navegador, puedes perder el control de tus aportaciones. El servidor guarda el hash del identificador, tus aportaciones y acciones asociadas. Para limitar altas calcula una señal horaria con clave a partir de la IP. La aplicación no guarda la IP completa. Cloudflare procesa la verificación de seguridad. La sesión no implica anonimato absoluto.

La aplicación vacía el texto al eliminarlo. La moderación puede conservar registros mínimos para atender denuncias o resolver abusos. Antes de abrir al público, el responsable debe completar el aviso con los plazos efectivos, los datos de contacto y la vía para ejercer derechos.
