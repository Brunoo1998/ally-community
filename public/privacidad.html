Privacidad

La cookie técnica de sesión dura hasta 180 días y se renueva con el uso. Puedes leer sin perfil; para participar elige un seudónimo público único. Si borras las cookies o cambias de dispositivo, necesitarás el código de recuperación. El servidor guarda el hash de las credenciales y del código, el nombre público, la fecha de creación, el rol y las aportaciones y acciones asociadas. No se identifica tu hardware ni se solicita correo electrónico. El código de recuperación es privado y permite acceder al perfil; puedes renovarlo. Para limitar altas calcula una señal horaria con clave a partir de la IP. La aplicación no guarda la IP completa. Cloudflare procesa la verificación de seguridad. La sesión no implica anonimato absoluto.

La aplicación vacía el texto al eliminarlo. La moderación puede conservar registros mínimos para atender denuncias o resolver abusos. Antes de abrir al público, el responsable debe completar el aviso con los plazos efectivos, los datos de contacto y la vía para ejercer derechos.
